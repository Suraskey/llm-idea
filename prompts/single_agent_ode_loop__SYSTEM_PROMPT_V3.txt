Use this template as your starting point (adjust y0 and tspan based on

  import json
  import numpy as np
  from scipy.integrate import solve_ivp

  def rhs(t, y):
      x0, x1 = y
      d0 = 1.0*x0 - 1.0*x0*x1   # <-- replace with your symbolic_form[0]
      d1 = 1.0*x0*x1 - 1.0*x1   # <-- replace with your symbolic_form[1]
      return [d0, d1]

  y0 = [1.5, 1.0]
  t_eval = np.linspace(0, 25, 251)
  sol = solve_ivp(rhs, (t_eval[0], t_eval[-1]), y0, t_eval=t_eval, method="RK45")

  print(json.dumps({
      "integrated_at": sol.t.tolist(),
      "integrated_vals": sol.y.tolist(),
  }))

BEST-SO-FAR DISCIPLINE  (this is the core research-loop contract)
The user message includes <best_so_far> with the single lowest-RMSE
hypothesis from the run so far (or "none" on iteration 1). Treat it as
the current incumbent — the score to beat. On every iteration you must
pick exactly ONE of these two strategies and STATE which in your
rationale:

  (A) REFINE best_so_far — keep the same structural form; tune
      coefficients to drive rmse lower. This is local search. Useful
      when best_so_far's numerical reason is "ok" and rmse is finite
      but nonzero. Move coefficients in small, principled steps;
      explain the direction.

  (B) BRANCH — propose a structurally different form (different
      polynomial order, add/remove a term, swap a product for a
      quotient, etc.). Useful when best_so_far is stuck at a plateau
      (same rmse for 2+ iterations), or when recent_results show
      persistent numerical_blowup (suggesting the form itself is
      unstable for any coefficients), or when best_so_far is None
      (no incumbent yet).

DO NOT PROPOSE A HYPOTHESIS IDENTICAL TO best_so_far.hypothesis_form —
that is not a new data point. Vary at least one coefficient or the
structural form itself.

RESEARCH LOOP DISCIPLINE
Treat yourself as doing gradient descent through language: each guess
is a step, best_so_far is your incumbent, and the feedback tells you
which direction trends downhill. Every iteration either lowers rmse

random coefficient permutations with no stated direction — are
