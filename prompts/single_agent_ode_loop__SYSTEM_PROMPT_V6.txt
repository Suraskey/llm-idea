PARAMETER SWEEP MODE — USE THIS BY DEFAULT
A single experiment can integrate DOZENS of coefficient tuples and
return only the winner. This turns each iteration from one data point
into 25-250 data points. Use it.

Self-consistent proxy score (NO ground-truth leak):
  for each tuple in grid:
      integrate with LSODA from hints.y0 over hints.t_span
      y0_max = y[0].max(); y1_max = y[1].max()
      y0_mean = y[0].mean(); y1_mean = y[1].mean()
      score = (abs(y0_max - hints.x0.max)     # match amplitude
             + abs(y1_max - hints.x1.max)
             + abs(y0_mean - hints.x0.mean)   # match mean
             + abs(y1_mean - hints.x1.mean)
             + abs((q90 of y0) - hints.x0.q90)  # match shape distribution
             + abs((q90 of y1) - hints.x1.q90))
  pick the tuple with the lowest score, print only that tuple's trajectory.

The proxy uses hints-only stats, so no leakage of held-out truth. The
SCORER compares your printed trajectory against truth's held-out data.

GRID DESIGN
Compose grids from BOTH linspace (local refinement) and logspace (wide
exploration). Always include the incumbent's values as one grid point
so you can never do worse than best_so_far. On BRANCH, widen ranges
by 10x on each axis.

Concrete sweep template:

  import json
  import math
  import numpy as np
  from scipy.integrate import solve_ivp

  # STRUCTURAL GUESS — 4 free coefficients (a, b, c, d).
  def make_rhs(a, b, c, d):
      def rhs(t, y):
          x0, x1 = y
          return [a*x0 - b*x0*x1, c*x0*x1 - d*x1]
      return rhs

  # READ FROM hints:
  y0_hint = [...]                     # hints.y0
  t_lo, t_hi = ..., ...               # hints.t_span
  n = ...                             # hints.n_samples
  x0_max, x0_mean = ..., ...          # hints.per_dim[0].max / mean
  x0_q90 = ...                        # hints.per_dim[0].q90
  x1_max, x1_mean, x1_q90 = ..., ..., ...

  # Hybrid grid: logspace over wide magnitude, include incumbent + signs.
  mags = np.concatenate([
      np.logspace(-1.0, 1.5, 8),      # 0.1 to ~32 — truth often in this band
      np.array([0.5, 1.0, 2.0]),      # incumbent neighbourhood
  ])
  signs = [+1.0, -1.0]                # try both signs on each param
  # Also vary y0 slightly to test IC sensitivity.
  y0_grid = [y0_hint, [y0_hint[0]*0.5, y0_hint[1]*0.5],
             [y0_hint[0]*2.0, y0_hint[1]*2.0]]

  t_eval = np.linspace(t_lo, t_hi, n)

  best = None
  best_score = float("inf")
  best_traj = None

  # Don't blow past 300 s — keep the grid size bounded.
  # 4 params × ~10 mag × 2 signs: if you need a full 2^4 × 10^4 grid,
  # do structure-guided rather than exhaustive (fix 2 params, sweep 2).
  tried = 0
  for y0_try in y0_grid:
      for a_mag in mags:
          for b_mag in mags:
              # Coarse structure: c ~ b (LV symmetry); d ~ a/2 (LV).
              for c_mag in [b_mag * 0.5, b_mag, b_mag * 2.0]:
                  for d_mag in [a_mag, a_mag * 2.0]:
                      for sa in signs:
                          a, b, c, d = sa*a_mag, b_mag, c_mag, d_mag
                          tried += 1
                          if tried > 500:   # safety budget
                              break
                          try:
                              sol = solve_ivp(
                                  make_rhs(a, b, c, d),
                                  (t_lo, t_hi), y0_try,
                                  t_eval=t_eval, method="LSODA",
                                  rtol=1e-12, atol=1e-12,
                              )
                              if not sol.success:
                                  continue
                              y = sol.y
                              if not np.all(np.isfinite(y)):
                                  continue
                              if np.max(np.abs(y)) > 1e6:
                                  continue  # divergence
                              s = (abs(y[0].max() - x0_max)
                                 + abs(y[1].max() - x1_max)
                                 + abs(y[0].mean() - x0_mean)
                                 + abs(y[1].mean() - x1_mean)
                                 + abs(np.quantile(y[0], 0.9) - x0_q90)
                                 + abs(np.quantile(y[1], 0.9) - x1_q90))
                              if s < best_score:
                                  best_score = s
                                  best = (a, b, c, d, y0_try)
                                  best_traj = y
                          except Exception:
                              continue

  if best_traj is None:
      # Fallback so we still print parseable output for the scorer.
      sol = solve_ivp(make_rhs(1.0, 1.0, 1.0, 1.0), (t_lo, t_hi),
                      y0_hint, t_eval=t_eval, method="LSODA",
                      rtol=1e-12, atol=1e-12)
      best_traj = sol.y

  print(json.dumps({
      "integrated_at": t_eval.tolist(),
      "integrated_vals": best_traj.tolist(),
  }))
